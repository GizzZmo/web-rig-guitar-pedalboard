Can this use Core Audio and ASIO? A page running in Chrome/Safari/Edge/Firefox cannot open Steinberg ASIO itself. On macOS the browser already talks to Core Audio. On Windows it talks to WASAPI (usually shared mode). That is close enough to be playable with a proper interface and headphones, but it is not the same as a native ASIO DAW at 64-sample buffers.

For the lowest feel: use Chrome, a USB audio interface with an instrument (Hi-Z) input, headphones, and disable system audio enhancements. Then click Start and pick that interface for both input and output. Expected round-trip is often ~12–30 ms. True 3–8 ms ASIO monitoring still needs a native app (JUCE, Pedalboard, Neural Amp Modeler standalone, or an Electron shell wrapping this UI).
